# Description
[Shizuku](https://github.com/RikkaApps/Shizuku) utilities for [Termux](https://github.com/termux/termux-app)

# Requirements
- [Shizuku](https://github.com/RikkaApps/Shizuku) installed and running  
- Installed [Termux](https://github.com/termux/termux-app)

# How to install
## Via GitHub
1. Download deb file from latest release:
<p align="left">
  <a href="https://github.com/AlexeiCrystal/termux-shizuku-tools/releases/latest">
    <img src="assets/get-it-on-github.png" alt="Get it on GitHub" height="80">
  </a>
</p>

2. Install package:  
```
dpkg -i termux-shizuku-tools_5.0.deb
```

# Commands
```
Usage: shizuku, shk <command>

Commands:
  status, st, i, info  - Show Shizuku status & info
  open, o              - Open Shizuku app
  stop, s              - Stop Shizuku server
  execute, exec, e     - Execute command via Shizuku
  shell, sh            - Start interactive Shizuku shell
  config, cfg
    get                - Get config
    get key            - Get config key
    set key value      - Set config key
    reset              - Reset config
    reset key          - Reset config key
  help, h              - Show this help
  version, v           - Show utility version

Examples:
  shizuku info
  shizuku exec "pm list packages"
  shizuku config set package your.custom.shizuku.package
  shizuku shell
```

# How to build
1. Download [repository as zip](https://github.com/AlexeiCrystal/termux-shizuku-tools/archive/refs/heads/main.zip)  
Or clone via git:  
```
git clone https://github.com/AlexeiCrystal/termux-shizuku-tools.git
```

2. Build package:  
```
make package
```

3. Install package:  
```
dpkg -i termux-shizuku-tools.deb
```
